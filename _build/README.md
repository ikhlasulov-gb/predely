# Пределы обоснования

Статическая энциклопедия по книге Викулов Ихлас Сергеевич «О неполноте достаточно сложных формальных систем и пределах имманентного обоснования»
(Четвёртое издание, исправленное, 24 ноября 2026 г.).

## Как открыть

Сайт полностью статический. Его можно открыть напрямую:

    xdg-open index.html

Лучше запустить локальный сервер:

    python3 -m http.server 8000

и открыть <http://localhost:8000/>.

## Как собрать заново

Из каталога сайта:

    python3 -m _build.build

Сборщик читает `book.tex` из пути, заданного переменной окружения
`PREDELY_SOURCE_FILE` (по умолчанию — `source/book.tex`), и перезаписывает
`articles/`, `terms/`, `assets/` и основные страницы. Дополнительно можно
задать `PREDELY_COVER_FILE`, `PREDELY_COVER_JSON` и `PREDELY_PDF_FILE`.

## Что внутри

- `articles/` — 76 статей книги;
- `terms/` — словарные статьи;
- `assets/` — CSS, JS, KaTeX, шрифты, поисковый индекс;
- `predely-obosnovaniya.pdf` — готовый PDF книги;
- `_build/BUILD-REPORT.md` — отчёт о сборке и сверке.

Текст книги не переписывался. Добавлены только навигация, ссылки, поиск,
словарь, указатели и постоянные ссылки на фрагменты.
