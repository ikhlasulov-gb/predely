Программа Гильберта и условия теорем о неполноте

Программа, для которой теоремы о неполноте составили границу, была программой имманентного обоснования математики. Гильберт поставил задачу [111]: обосновать математику конечными, финитными средствами. Требовалось доказать непротиворечивость арифметики и анализа рассуждениями, не выходящими за пределы их синтаксиса, и тем самым избавить математику от внешних оснований. Требование имело ту же структуру, что и требование имманентного обоснования реальности: система удостоверяет сама себя. Замысел был сформулирован точно. Условия его выполнимости установлены с той же точностью. Установление совпало с опровержением: границы применимости оказались границами самого замысла.

Условия теорем фиксируются для системы T. Язык есть арифметика первого порядка с нулём 0, операцией следования S, сложением и умножением. Формулы строятся равенством, отношением порядка и кванторами по натуральным числам. Замкнутые формулы называются предложениями. Минимальная база — арифметика Робинсона Q: конечный перечень аксиом следования, сложения и умножения, в котором представимы все вычислимые функции. Аксиоматизация эффективна: множество аксиом разрешимо алгоритмом. Поэтому вычислимо отношение «m есть номер вывода формулы с номером n». Система, содержащая Q и эффективно аксиоматизированная, есть достаточно сложная система в смысле введённого определения. Арифметика Пеано и теория множеств ZF удовлетворяют обоим условиям. Границы теорем распространяются на всякую теорию, в которую арифметика интерпретируема (Тарский, Мостовский, Робинсон [332]).

Гёделева нумерация переносит синтаксис в арифметику [129]. Символам языка сопоставлены различные натуральные числа. Конечная последовательность номеров (a_1,…,a_k) кодируется числом 2^a_1· 3^a_2·s p_k^a_k, где p_k — k-е простое число. Разложение на множители восстанавливает последовательность, и кодирование обратимо. Всякий синтаксический объект, терм, формула или вывод, получает номер. Номер формулы φ обозначается ⌜φ⌝. Цифрой n называется терм, полученный n-кратным применением операции следования к нулю. Запись ψ(⌜φ⌝) сокращает подстановку цифры числа ⌜φ⌝ вместо свободной переменной. Подстановка цифры в формулу и проверка последовательности формул на выводимость вычислимы. Этим определяется вычислимость всех дальнейших метаматематических отношений.

Представимость доставляет перевод вычислимого в выводимое [189]. Для всякого вычислимого отношения R существует формула ρ, для которой истинность R(n_1,…,n_k) влечёт T⊢ρ(n_1,…,n_k), а ложность влечёт T⊢¬ρ(n_1,…,n_k). Для всякой вычислимой функции существует формула графика δ, для которой T выводит значение на всяком наборе цифр и его единственность. Отношение Prf_T(m,n), «m есть номер вывода формулы с номером n», вычислимо и представимо формулой, обозначаемой так же. Предикат доказуемости определяется через него: Prov_T(n) есть формула ∃ m Prf_T(m,n). Для предложения φ запись Prov_T(⌜φ⌝) читается «в T существует вывод φ». Высказывание о выводимости стало арифметическим предложением. Система получила язык для суждений о собственных доказательствах.

Два производных условия фиксируются отдельно. ω-непротиворечивость означает, что не существует формулы ψ(x), для которой T⊢∃ x ψ(x) и одновременно T⊢¬ψ(m) для каждого числа m. Всякая ω-непротиворечивая система непротиворечива, обратное неверно. Стандартная модель ℕ есть натуральный ряд с обычными операциями. Истинность в ℕ есть арифметическая истина в точном смысле. Формулы представления выбираются канонические: в ℕ они выражают представляемые отношения точно, без остатка. Оба условия употребляются в следующем разделе. ω-непротиворечивость — в исходной форме первой теоремы. Точность представления — при установлении истинности гёделева предложения.
