# Пределы обоснования

Статическая энциклопедия по книге Викулова И. С. «О неполноте достаточно сложных формальных систем и пределах имманентного обоснования».

**Сайт:** https://ikhlasulov.github.io/predely/

## Что в репозитории

- `index.html`, `contents.html`, `search.html` — главная, содержание и поиск;
- `articles/` — 76 статей по разделам книги;
- `terms/` — словарные статьи;
- `assets/` — CSS, JavaScript, KaTeX, шрифты, поисковый индекс;
- `predely-obosnovaniya.pdf` — готовая книга в PDF;
- `_build/` — генератор сайта на Python.

## Сборка

Генератор читает `book.tex` из пути, указанного в `_build/config.py`,
и пересобирает статьи, словарь, поисковый индекс и основные страницы:

```bash
python3 -m _build.build
```

Локальный просмотр:

```bash
python3 -m http.server 8000
```

и открыть <http://localhost:8000/>.
